# 任务清单：账号与基础数据

按依赖顺序排列，每项独立可验证。

## 阶段一：数据层

- [x] **T001 数据准备（已完成）**
  `docs/seed.sql` 已执行，实测：角色 5、权限 28、角色授权 36、用户 2、类别 6。
  *验收*：`SELECT COUNT(*) FROM t_user` = 2，`admin` 账号可登录（待后端完成后验证）。

- [ ] **T002 补基础数据样本**
  当前 `t_source_party`、`t_cert_org` 为空。演示需要至少 8 个来源方（4 供应商、2 加工师傅、2 同行商户）与 2 个鉴定机构。
  *验收*：三类来源方都有数据，货品建档时下拉可选。

## 阶段二：后端认证

- [ ] **T003 SpringBoot 骨架 + JWT**
  依赖 Web、MyBatis-Plus、MySQL Driver、Validation、jjwt。配置 datasource 指向 `db:3306/db_jade`，Jackson 时区 `Asia/Shanghai`。
  *验收*：`GET /api/health` 返回 200。

- [ ] **T004 登录接口 `POST /api/auth/login`**
  按用户名查用户，BCrypt 校验口令，查角色与权限并集，签发 JWT（8 小时）。
  *验收*：admin/123456 登录取到 token，permissions 含 18 条。

- [ ] **T005 登录失败锁定**
  内存缓存 `(username → 失败次数, 锁定截止)`。连续 5 次错误锁 10 分钟，返回 423；登录成功清零。
  *验收*：连错 5 次后用正确口令仍返回 423；等 10 分钟或重启后恢复。

- [ ] **T006 鉴权拦截器 + 权限注解**
  解析 `Authorization` 头，校验签名与过期，用户信息放 `ThreadLocal`；`@RequirePerm("UC-xx")` 比对权限集合。
  *验收*：不带 token 访问 `/api/auth/me` 返回 401；销售访问 `/api/users` 返回 403。

- [ ] **T007 当前用户与改密**
  `GET /api/auth/me`、`PUT /api/auth/password`。改密校验旧口令，新口令 8 位以上含字母数字。
  *验收*：改密后用新口令登录成功，旧口令失败。

## 阶段三：后端账号与基础数据

- [ ] **T008 账号管理接口**
  `GET/POST/PUT /api/users`、`GET /api/roles`、`GET /api/permissions`。
  *验收*：开通 merchant01 分配「合作商户」，该账号登录后 permissions 只有 UC-11、UC-26。

- [ ] **T009 老板账号保护**
  停用自己账号时返回 409。
  *验收*：admin 停用 admin 被拒。

- [ ] **T010 来源方 CRUD**
  `GET/POST/PUT/DELETE /api/source-parties`，`(party_type, name)` 唯一，删除前查引用计数。
  *验收*：新增重名返回 409；删除被 12 件货品引用的来源方返回 409 且带 refCount。

- [ ] **T011 鉴定机构 CRUD**
  同 T010，引用表为 `t_inspection`。
  *验收*：基本增删改查通过。

## 阶段四：前端

- [ ] **T012 登录页**
  用户名、口令两个输入框，错误提示区分 401 / 423 / 403。
  *验收*：口令错显示「用户名或口令错误」；锁定显示剩余时间。

- [ ] **T013 token 管理 + 路由守卫**
  token 存 localStorage，Axios 请求拦截器自动带 `Authorization`；403 与 401 分别处理。
  *验收*：刷新页面不丢登录态；token 过期跳回登录页。

- [ ] **T014 菜单与按钮权限**
  按 `permissions` 生成菜单，无权限的按钮置灰。
  *验收*：销售登录后看不到「账号管理」菜单。

- [ ] **T015 账号管理页**
  列表（用户名、姓名、角色、状态）+ 开通弹窗（多选角色）+ 停用按钮。
  *验收*：开通一个外部账号后能立即登录。

- [ ] **T016 基础数据页**
  三个 tab：来源方、鉴定机构、货品类别。支持增改停用删除，删除被拒时提示改停用。
  *验收*：删除被引用的来源方，弹出「已被 12 件货品引用，只能停用」。
