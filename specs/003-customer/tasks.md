# 任务清单：客户与到店

## 阶段一：后端客户

- [ ] **T001 客户实体与标签**
  `Customer`、`CustomerTag` 两个实体；标签用独立表，不用逗号串。
  *验收*：一个客户挂两个标签，`SELECT * FROM t_customer_tag WHERE customer_id=?` 返回两行。

- [ ] **T002 客户 CRUD `GET/POST/PUT /api/customers`**
  手机号唯一冲突时返回 409 并带出原档案；渠道与标签枚举校验；朋友介绍必须有介绍人。
  *验收*：AC-01、AC-02 通过；重复手机号时前端能拿到原客户 id 跳转。

- [ ] **T003 客户购买记录 `GET /api/customers/{id}/purchases`**
  从 `t_sale` 汇总，标出是否已退货。
  *验收*：AC-03 通过；有退货的成交显示 `returned: true`。

## 阶段二：后端公开浏览

- [ ] **T004 公开货品列表与详情**
  `GET /api/public/goods`、`GET /api/public/goods/{goodsNo}`。**DTO 里不能有价格字段**。
  *验收*：AC-04、AC-05、AC-06 通过；用 `curl` 抓响应，全文搜 `price` 无结果。

- [ ] **T005 推荐位筛选**
  `featured=true` 时只返回 `is_featured=1` 的 94 件；不传则返回全部 679 件。
  *验收*：两个数量都对得上。

## 阶段三：后端预约

- [ ] **T006 提交预约 `POST /api/public/reservations`**
  手机号格式校验、货品须在柜、到店时间须为 `yyyy-MM-dd HH:mm` 且落在「+2 小时」至「+5 天」窗口内、同号当日重复预约返回 409 带原编号。
  *验收*：AC-07、AC-08、AC-17、AC-18 通过。

- [ ] **T007 查预约 `GET /api/public/reservations?phoneTail=`**
  只返回待确认且时段未过期的；结果不含姓名与完整手机号；加 IP 限流（10 次/分钟）与条数上限 20。
  *验收*：AC-09、AC-10 通过；快速请求 15 次，第 11 次返回 429。

## 阶段四：后端预定

- [ ] **T008 额度查询与提交预定**
  额度按 `status IN ('待到店','已联系','已爽约','已取消')` 计数，≥3 返回 422；同货品已有有效预定返回 409。
  *验收*：AC-11、AC-12 通过；同一号码连续预定 3 件不同货品后，第 4 件被拒。

- [ ] **T009 当日到店名单 `GET /api/bookings/today`**
  只含今日、状态待到店或已联系，按 `submit_time` 升序。
  *验收*：AC-15 通过。

- [ ] **T010 标记已联系 `POST /api/bookings/{id}/contact`**
  写 `contact_time`、状态改已联系；重复标记返回 409。
  *验收*：AC-16 通过。

- [ ] **T011 登记到店结论 `POST /api/bookings/{id}/result`**
  到店→已达成并释放额度；未到→已爽约不释放。响应带剩余额度。
  *验收*：AC-13、AC-14 通过。

- [ ] **T012 货品预留与取消预留**
  `POST /api/goods/{id}/reserve`、`/unreserve`，改货品状态并写流水，不动 `t_booking.status`。
  *验收*：预留后货品显示「预留」，公开列表里消失；取消预留后回来。

## 阶段五：前端

- [ ] **T013 客户档案页**
  列表（编号、姓名、手机号、渠道、标签）+ 新建/编辑弹窗；标签多选。
  *验收*：按标签「大客户」筛选，结果正确。

- [ ] **T014 客户详情页**
  基本信息、偏好、标签、购买记录列表（带退货标记）、手机号一键复制。
  *验收*：点复制后剪贴板有号码。

- [ ] **T015 小程序首页**
  上部推荐区（`featured=true`，94 件里取前 8–12 件横滑）、下部全部库入口。
  *验收*：推荐区只出现精选货品，与全部库能明显区分。

- [ ] **T016 小程序全部库**
  卡片流，按类别/器型筛选，无限滚动或分页。
  *验收*：679 件都能翻到，图正常加载。

- [ ] **T017 小程序货品详情 + 预约/预定表单**
  展示图、品名、类别、尺寸、描述（无价格）；底部两个按钮：预约看货、预定。
  *验收*：提交预约拿到编号；预定第 4 次被拒并提示额度已满。

- [ ] **T018 当日到店名单页**
  列表带手机号、货品、时段、状态；标记已联系、登记到店/未到。
  *验收*：登记「到店」后该条从名单消失，额度 +1。

## 阶段六：验收

  *验收*：AC-01~AC-16 全通过或差异在案。

## 依赖关系

```
T001 → T002 → T003
T004 → T005
T006 → T007
T008 → T009 → T010 → T011
                    └──→ T012
                          ↓
T013 → T014 → T015 → T016 → T017 → T018 → T019
```

后端三块（客户 / 公开浏览 / 预约预定）可并行；前端 T015 依赖 T005。

## 与其他 feature 的交界

- 依赖 `001-goods` 的货品状态机：预留、取消预留会改货品状态
- 依赖 `002-sale` 的成交记录：客户购买记录从这里汇总
- 与 `006-processing` 无关：上门预约是另一张表 `t_visit_appt`，不要混用
