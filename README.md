## 关于微信小程序

外部协同端按设计做成微信小程序，代码在 `miniprogram/`：首页与在售、货品详情、预约看货、查预约，以及供应商出让申请、加工任务、调货价目、预约上门、完工提交。导入微信开发者工具即可运行。

对外演示用 H5（`mini.html`、`external.html`），原因是小程序上线需要备案：

1. 小程序线上版只能请求已备案的 HTTPS 域名，不能是 IP 加端口；服务器现在是公网 IP 直连。
2. 服务器用自签证书，微信内置浏览器会拦截。
3. 未发布的小程序只有开发者与体验成员（上限 15 人）能打开。

演示走两条路：

- **客户侧与外部协同**：H5 版，与小程序共用同一套后端接口与校验规则。
- **小程序本体**：微信开发者工具导入 `miniprogram/`，本地模拟器演示；需要评审人自己打开时，在公众平台加为体验成员。

将来有备案域名后，把 `utils/api.js` 里的 `BASE` 换成该域名、在公众平台配置 request 合法域名，即可发布。

## 技术栈

| 层 | 选型 |

## 本地启动

```bash
# 1. 数据库（假设 MySQL 已在跑）
mysql -uroot -p < docs/schema.sql
mysql -uroot -p < docs/demo-goods.sql
mysql -uroot -p < docs/demo-goods-image.sql
mysql -uroot -p < docs/demo-sales.sql
mysql -uroot -p < docs/demo-business.sql

# 2. 后端（默认连 127.0.0.1:3307；数据源与密钥均走环境变量，没有内置默认口令）
export DB_PORT=3307 DB_USER=root DB_PWD=你的数据库口令
cd server && mvn spring-boot:run

# 3. 打开
open http://127.0.0.1:8080
```

环境变量：

| 变量 | 必填 | 说明 |
|---|---|---|
| `DB_PORT` / `DB_USER` / `DB_PWD` | 是 | 数据源；口令不再有仓库内默认值 |
| `JADE_JWT_SECRET` | 正式部署必填 | 令牌签名密钥，≥32 字节；仓库默认值只供演示 |
| `JADE_JWT_ENC_SECRET` | 可选 | 载荷加密密钥；留空由签名密钥派生 |
| `JADE_JWT_EXPIRE_HOURS` | 可选 | 令牌有效期，默认 8 |
| `MYBATIS_LOG` | 可选 | 设为 `org.apache.ibatis.logging.stdout.StdOutImpl` 才打印 SQL，默认关闭 |

## 关键设计决定

**一、公开接口独立前缀**

客户侧免登录接口统一在 `/api/public/**` 下。拦截器只配一条「放行该前缀」，其余接口默认要求登录——包括没写权限注解的接口，避免漏配。

**二、浏览接口在 DTO 层裁价格**

`/api/public/goods` 的响应里没有 `price`、`cost`、`min_price`、`transfer_price` 任何一项。前端隐藏字段防不住抓包，服务端不给才是真的不给（UC-09 设计约束）。

**三、逾期不落库**

分期计划的 `status` 只写「未还」和「已结清」，逾期由查询时算 `next_due_date < CURDATE() AND paid_amount < 总额`。避免每天跑批改状态。

**四、编号用时间戳而非流水号**

`CJ20261023051234` 这样的格式，前 2 位是业务类型，中间是时间，末 2 位随机。不用「查当日最大序号 +1」——并发下两个请求会拿到同一个最大值，撞唯一索引直接 500。

**五、调货金额不固化**

`t_transfer` 没有金额字段，结算时按 `COALESCE(transfer_price, min_price)` 实时取。代价是货品调价后历史结算金额会失真，已在 `specs/004-transfer` 记为差异。
